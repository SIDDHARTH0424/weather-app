# Weather App

Search any city and see its current weather. Built with HTML, CSS and JavaScript using `fetch()` and the free Open-Meteo API (no API key needed).

- Handles three states: loading, error (city not found or network failure) and success
- Live: https://siddharth0424.github.io/weather-app/

## Run
Open `index.html` in a browser (or use VS Code Live Server).
